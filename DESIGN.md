# Sumway Design System

## Visual Identity
- **Primary Color (Accent Coral/Red)**: `#FF555F` - A vibrant coral that symbolizes digital workforce energy, dynamic transformation, and recruitment speed.
- **Secondary Color (Accent Teal)**: `#4AABCA` - A sleek modern teal representing trust, BPO reliability, and IT architecture excellence.
- **Background (Dark Mode)**: `#0A1128` - A deep midnight navy blue background that feels extremely premium and modern.
- **Surface/Card Background (Dark Mode)**: `#1E345C` - A navy blue card background with low-opacity glassmorphism overlays (`rgba(30, 52, 92, 0.75)`).
- **Text Color (Dark Mode)**: Primary text in `#FFFFFF`, with muted metadata text in Slate Gray `#94A3B8`.
- **Background (Light Mode)**: `#FFFFFF` - A clean white canvas.
- **Text Color (Light Mode)**: `#1E345C` - High-contrast navy headers and neutral charcoal gray body text `#58595B`.
- **Typography**: 
  - Headline Font: `Outfit` (sleek, geometric, modern digital brand look).
  - Body Font: `Inter` (neutral, high-readability sans-serif).
- **Corner Roundness**: `ROUND_EIGHT` (`8px`) for buttons, cards, and input fields to give a contemporary tech-firm aesthetic.
- **Spacing Scale**: Consistent spacing to emphasize breathing room and clean grid alignments.
